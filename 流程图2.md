## 一、整体架构：两阶段流水线

```
                         ┌─────────────┐
                         │   开   始    │
                         └──────┬──────┘
                                │
                                ▼
          ┌─────────────────────────────────────────┐
          │                                         │
          │         阶段一：LangGraph 图执行          │
          │     (自动循环 LLM ↔ Tools，收集信息)      │
          │                                         │
          │   ┌──────┐  有tool_calls  ┌───────┐     │
          │   │ llm  ├──────────────→│ tools │     │
          │   └──┬───┘               └───┬───┘     │
          │      │ 无tool_calls          │         │
          │      ▼                       │         │
          │   (阶段一结束)  ←─────────────┘         │

          └─────────────────┬───────────────────────┘

                            ▼
          ┌─────────────────────────────────────────┐

## 二、阶段一详解：LangGraph 图执行

```
                         ┌──────────────────────┐
                         │       START           │
                         └──────────┬───────────┘
                                    │
                                    ▼
                              ┌──────────┐
                              │          │
                         ┌───→│ llm 节点 │
                         │    │          │
                         │    └────┬─────┘
                         │         │
                         │    ┌────┴────┐
                         │    │ 有tool  │  should_continue()
                         │    │ _calls? │  条件边
                         │    └──┬──┬──┘
                         │    是 │  │ 否
                         │       │  │
                         │       │  └──────────┐
                         │       ▼              │
                         │  ┌─────────┐         │
                         │  │         │         │
                         └──┤ tools   │         ▼
                            │ 节点    │     ┌─────┐

### 2.2 单次 llm → tools → llm 循环的详细流程

```
    ┌──────────────────────────────────────────────────────┐
    │                    llm 节点 (call_llm)                │
    │                                                      │
    │  输入: State.messages                                │
    │        State.iteration_count                         │
    │                                                      │
    │  ┌────────────────────────────────────┐              │
    │  │ model_with_tools.stream(messages)  │              │
    │  │ 逐 token 打印思考过程               │              │
    │  │ chunk + chunk → 合并为完整 AIMessage│              │
    │  └────────────────┬───────────────────┘              │
    │                   │                                  │
    │                   ▼                                  │
    │  ┌────────────────────────────────────┐              │
    │  │  full_message 有 tool_calls?       │              │
    │  └──────┬──────────────┬──────────────┘              │
    │      有 │              │ 无                          │
    │         │              ▼                              │
    │         │   打印 "不再需要工具"                        │
    │         │   返回 AIMessage (无 tool_calls)            │
    │         │                                             │
    └─────────┼─────────────────────────────────────────────┘
              │
              ▼  (有 tool_calls 时)
    ┌──────────────────────────────────────────────────────┐
    │                  tools 节点 (call_tools)              │
    │                                                      │
    │  遍历 last_message.tool_calls:                       │
    │                                                      │
    │  ┌────────────────────────────────────┐              │
    │  │ tool_call["name"] → tools_by_name │              │
    │  │ tool.invoke(tool_args)             │              │
    │  │ json.dumps(result)                 │              │
    │  │ result[:3000] 截断                 │              │
    │  │ → ToolMessage(content, tool_call_id)│             │
    │  └────────────────┬───────────────────┘              │
    │                   │                                  │
    │  返回: {"messages": [ToolMessage, ...]}              │
    │        (add_messages 自动追加到 State)                │
    │                                                      │
    └──────────────────┬───────────────────────────────────┘
                       │
                       │  (普通边，总是回到 llm)
                       ▼
                 回到 llm 节点
```

## 三、State 驱动的数据流

```
    ┌─────────────────────────────────────────────────────────┐
    │                    AgentState                           │
    ├─────────────────────────────────────────────────────────┤
    │                                                         │
    │  messages: Annotated[list, add_messages]                │
    │  ┌────────────────────────────────────────────────┐    │
    │  │ [SystemMessage, HumanMessage]                    │    │
    │  │        +                                         │    │
    │  │ llm 返回 → [AIMessage(tool_calls=[...])]         │    │
    │  │        +                                         │    │
    │  │ tools 返回 → [ToolMessage(...), ToolMessage(...)]│    │
    │  │        +                                         │    │
    │  │ llm 返回 → [AIMessage(tool_calls=[...])]         │    │
    │  │        +                                         │    │
    │  │ tools 返回 → [ToolMessage(...)]                  │    │
    │  │        +                                         │    │
    │  │ llm 返回 → [AIMessage(content="最终文本")]        │    │
    │  │        ↓                                         │    │
    │  │  最终: 完整的对话历史 (传给阶段二)                 │    │
    │  └────────────────────────────────────────────────┘    │
    │                                                         │
    │  iteration_count: int                                   │
    │  ┌────────────────────────────────────────────────┐    │
    │  │ 每轮 llm 调用 +1，直接覆盖（无特殊 Reducer）     │    │
    │  │ 用于日志输出和迭代追踪                           │    │
    │  └────────────────────────────────────────────────┘    │
    │                                                         │
    └─────────────────────────────────────────────────────────┘

    add_messages Reducer 的工作原理:
    ┌─────────────────────────────────────────────────────────┐
    │                                                         │
    │  llm 节点返回  {"messages": [AIMessage]}                │
    │                        ↓                                │
    │  LangGraph 调用 add_messages(old_list, [AIMessage])     │
    │                        ↓                                │
    │  追加到列表末尾 (而非覆盖)                               │
    │                                                         │
    └─────────────────────────────────────────────────────────┘
```

## 四、Manual Agent vs LangGraph 对照

```
    ┌──────────────────────────────────────────────────────────┐
    │              manual_agent.py (手写循环)                   │
    ├──────────────────────────────────────────────────────────┤
    │                                                          │
    │  messages = [SystemMessage, HumanMessage]                │
    │                                                          │
    │  for turn in range(1, max+1):                            │
    │      ┌─────────────────────────────────┐                │
    │      │ full_message = stream(messages) │  ← 你手动管理  │
    │      └───────────────┬─────────────────┘                │
    │                      │                                   │
    │      if not tool_calls:                                  │
    │          break                    ← 你手动判断           │
    │                      │                                   │
    │      for tc in tool_calls:                               │
    │          result = tool.invoke()   ← 你手动执行           │
    │          messages.append(ToolMessage) ← 你手动追加       │
    │                                                          │
    │  structured_output(messages)      ← 你手动调用           │
    │                                                          │
    └──────────────────────────────────────────────────────────┘

                              ⬇  LangGraph 替换  ⬇

    ┌──────────────────────────────────────────────────────────┐
    │            manual_agent2.py (LangGraph 图)                │
    ├──────────────────────────────────────────────────────────┤
    │                                                          │
    │  class AgentState(TypedDict):                            │
    │      messages: Annotated[list, add_messages]  ← 自动合并 │
    │      iteration_count: int                                │
    │                                                          │
    │  workflow = StateGraph(AgentState)                       │
    │  workflow.add_node("llm", call_llm)       ← 节点化       │
    │  workflow.add_node("tools", call_tools)                  │
    │  workflow.add_conditional_edges(          ← 自动路由     │
    │      "llm", should_continue,                             │
    │      {"tools": "tools", "end": END}                      │
    │  )                                                       │
    │  workflow.add_edge("tools", "llm")       ← 固定回路      │
    │  workflow.compile(checkpointer=MemorySaver())            │
    │                                                          │
    │  graph.stream(initial_state, config)    ← 自动步进       │
    │  # 循环、break、消息管理全由 LangGraph 接管              │
    │                                                          │
    └──────────────────────────────────────────────────────────┘
```

## 五、Checkpointer 的作用

```
    ┌─────────────────────────────────────────────────────────┐
    │              MemorySaver (内存快照)                       │
    ├─────────────────────────────────────────────────────────┤
    │                                                         │
    │  每一步执行后，LangGraph 自动保存 State 快照:            │
    │                                                         │
    │  config = {"configurable": {"thread_id": "session-1"}}  │
    │                                                         │
    │  ┌──────────┐    ┌──────────┐    ┌──────────┐          │
    │  │ Step 1   │ →  │ Step 2   │ →  │ Step 3   │ → ...    │
    │  │ llm 调用 │    │ tools执行│    │ llm 调用 │          │
    │  │  ✓ 快照  │    │  ✓ 快照  │    │  ✓ 快照  │          │
    │  └──────────┘    └──────────┘    └──────────┘          │
    │                                                         │
    │  用途:                                                  │
    │  1. 断点续传: 出错后可以从上一步继续                    │
    │  2. Human-in-the-Loop: 暂停等审批，再继续执行           │
    │  3. 调试: 回看任意步骤的完整 State                     │
    │  4. 跨请求记忆: 同一 thread_id 下次调用共享历史         │
    │                                                         │
    └─────────────────────────────────────────────────────────┘
```

## 六、核心概念速查

| 概念 | 对应代码 | 对应手写循环 |
|------|---------|-------------|
| **State** | `AgentState(TypedDict)` | `messages` 变量 + 手动管理 |
| **Node** | `add_node("llm", call_llm)` | 循环体中的 LLM 调用代码块 |
| **Node** | `add_node("tools", call_tools)` | 循环体中的工具执行代码块 |
| **条件边** | `add_conditional_edges("llm", should_continue, ...)` | `if not tool_calls: break` |
| **普通边** | `add_edge("tools", "llm")` | 循环末尾回到开头 |
| **Reducer** | `Annotated[list, add_messages]` | `messages.append()` |
| **Checkpointer** | `MemorySaver()` | 无（手动循环不保存快照） |
| **Recursion Limit** | `recursion_limit=20` | `max_iterations=10` |
| **Stream** | `graph.stream(..., stream_mode="values")` | `for event in ...` (stream_mode) |
