## 三种消息角色

```
┌────────────────────────────────────────────────────────────┐
│                      消息流转全景                           │
├─────────────┬──────────────────┬───────────────────────────┤
│  SystemMessage  │  HumanMessage    │  AIMessage / ToolMessage  │
│  (设定规则)     │  (用户提问)      │  (LLM决策 / 工具结果)      │
├─────────────┼──────────────────┼───────────────────────────┤
│              │                  │                            │
│  "你是硬件    │  "推荐2026       │  第1轮: AIMessage          │
│   配置大师"   │   年最好的配置"   │    └─ tool_calls: [搜索]   │
│              │                  │                            │
│              │                  │  第1轮: ToolMessage         │
│              │                  │    └─ "RTX 5090 售价..."   │
│              │                  │                            │
│              │                  │  第2轮: AIMessage          │
│              │                  │    └─ content: "最终JSON"  │
│              │                  │              ↑             │
│              │                  │         无 tool_calls      │
│              │                  │         循环终止           │
└─────────────┴──────────────────┴───────────────────────────┘
```

## 核心要点

| 步骤 | 谁在行动 | 做什么 |
|------|---------|--------|
| 决策 | LLM | 看消息历史，决定"直接回答"还是"调用工具" |
| 执行 | 你的代码 | 遍历 `response.tool_calls`，逐个调用 `tool.invoke()` |
| 观察 | 你的代码 | 把工具结果封成 `ToolMessage` 追加回消息列表 |
| 循环 | 你的代码 | 回到决策步骤，直到 LLM 不再要求工具 |
